# Reconly

Premium dark landing page for **Reconly** — a (fictional) B2B SaaS platform for
crypto accounting & compliance: crypto sub-ledger, DATEV-ready bookkeeping and
MiCA/AML reporting for companies holding digital assets.

- `site/` — the Next.js 15 + Tailwind v4 marketing site (see [site/README.md](site/README.md))
- `assets/` — brand source assets (glass ribbon mark, design sheet)

## Quick start

```bash
cd site
pnpm install
pnpm dev   # http://localhost:3001
```

Design language: "dark liquid glass" — pure black, strictly monochrome,
grey-to-white light, folded glass ribbon as the brand motif. Interactive hero
(cursor spotlight, ribbon tilt, particle field), logo marquee, rotating dot-globe
with connection arcs in the CTA band.

Software only — Reconly is not a financial service, no custody, no investment advice.
